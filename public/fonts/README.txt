MAKE1UP uses local Latin subsets of Bodoni Moda and DM Sans.
Downloaded from Google Fonts on 2026-10-16. No runtime font service is used.

Bodoni Moda, by indestructible type*.
https://fonts.google.com/specimen/Bodoni+Moda
https://github.com/google/fonts/tree/main/ofl/bodonimoda
Bodoni-Moda-OFL.txt contains the SIL Open Font License 1.1.

DM Sans, by Colophon Foundry and contributors.
https://fonts.google.com/specimen/DM+Sans
https://github.com/google/fonts/tree/main/ofl/dmsans
DM-Sans-OFL.txt contains the SIL Open Font License 1.1.

The font files are unmodified Google Fonts WOFF2 downloads.
The studio falls back to Georgia and system sans-serif when fonts are unavailable.
